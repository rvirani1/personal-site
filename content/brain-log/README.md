# Brain log

One file per entry, named `YYYY-MM-DD-some-slug.md`. The URL is `/brain-log/some-slug`.

```markdown
---
title: What I'm chewing on
date: 2026-10-23
tags: [ai, reading]
summary: Optional one-liner for lists, search and RSS. Defaults to the first ~180 characters.
draft: true            # optional: hide it until it's ready
ai:                    # optional: what your personal AI made of it
  summary: A short reflection written by your AI.
  threads:
    - A theme it noticed
    - A question worth coming back to
---

Write freely. Markdown works. Don't polish.
```

Entries tagged `archive: true` are the old riazv.me blog posts, kept for posterity.
